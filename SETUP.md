# GitHub profile README setup

The README uses your original animated layout, new documented projects and a controlled header **without auto-generated Go, HTML or CSS language chips**.

## Upload files

Upload the contents of this package to the repository `Mumuksh-Jain/Mumuksh-Jain` on its default branch:

- `README.md` (root)
- `.github/workflows/profile-activity.yml`
- `profile/signal-field-wide-dark.svg`
- `profile/signal-field-wide-light.svg`

The two SVGs initially show an honest “awaiting first run” placeholder, not fabricated activity. The workflow replaces these with actual GitHub GraphQL contribution figures, and also generates compact SVG variants.

## Activate the graph

1. In GitHub, open the profile repository's **Settings → Actions → General**. Allow GitHub Actions and ensure **Workflow permissions** permit **Read and write permissions** (or configure the repository so the workflow's declared `contents: write` permission is effective).
2. Open **Actions → Refresh profile activity card → Run workflow**. Run it on the default branch.
3. Wait for a successful run. Confirm `profile/signal-field-wide-dark.svg` and `profile/signal-field-wide-light.svg` now contain a chart, not the starter placeholder.
4. Hard-refresh the GitHub profile page. GitHub image caching may take several minutes.
5. The workflow runs daily at 03:17 UTC to update the chart.

This method does not depend on the previous broken third-party activity-graph host. The card is generated by [`shinpr/github-profile-stats`](https://github.com/shinpr/github-profile-stats) and served as a static SVG from the profile repository itself. Contribution totals can differ slightly from the visible GitHub profile based on the account/token's contribution visibility.
